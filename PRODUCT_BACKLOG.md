# Product Backlog - SIGCMI

## Project

**SIGCMI - Intelligent Medical Appointment Management System**

This document contains the initial Product Backlog for the SIGCMI project. The backlog is organized by user role and prioritized according to the project's needs.

---

# 🔵 Patient User Stories

| ID | Role | Name | User Story | Priority |
|----|------|------|------------|----------|
| UH-001 | Patient | Patient Registration | As a **patient**, I want to register in the system so that I can access the platform's services. | High |
| UH-002 | Patient | Patient Login | As a **patient**, I want to log in so that I can access my account. | High |
| UH-003 | Patient | Recover Password | As a **patient**, I want to recover my password so that I can regain access to my account. | High |
| UH-004 | Patient | Manage Profile | As a **patient**, I want to edit my personal information so that I can keep my profile up to date. | Medium |
| UH-005 | Patient | Schedule Appointment | As a **patient**, I want to schedule a medical appointment so that I can receive medical care. | High |
| UH-006 | Patient | Reschedule Appointment | As a **patient**, I want to reschedule my appointment so that it better fits my availability. | Medium |
| UH-007 | Patient | Cancel Appointment | As a **patient**, I want to cancel my appointment so that I can free my reserved time. | Medium |
| UH-008 | Patient | View Medical History | As a **patient**, I want to view my medical history so that I can review previous diagnoses and treatments. | Medium |
| UH-009 | Patient | Receive Notifications | As a **patient**, I want to receive appointment reminders so that I do not miss my appointments. | Low |
