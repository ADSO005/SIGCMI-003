# 🏥 SIGCMI

> **Intelligent Medical Appointment Management System**

SIGCMI - Intelligent Medical Appointment Management System built with Node.js, Express.js, Pug, Tailwind CSS, MySQL, Sequelize and JWT Authentication.

---

## 📋 Project Information

- **Project Name:** SIGCMI
- **Full Name:** Intelligent Medical Appointment Management System
- **Architecture:** Monolithic
- **Development Methodology:** Scrum
- **Version:** 1.0.0

---

## 🚀 Technologies

### Backend
- Node.js
- Express.js
- MySQL
- Sequelize ORM

### Authentication & Security
- JSON Web Token (JWT)
- Bcrypt
- Express Validator
- CSRF Protection
- Cookie Parser

### Frontend
- Pug (Template Engine)
- Tailwind CSS
- JavaScript

### Development Tools
- Git
- GitHub
- ESLint
- Prettier

## 🌿 Git Workflow

The project follows the Git Flow strategy.

```
main
develop
feature/*
```

Every new feature must be developed in a `feature/*` branch and merged into `develop` through a Pull Request.
